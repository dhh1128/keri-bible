# Field notes

Measurements of the deployed ecosystem, as opposed to the doctrine in `bible/`.

Everything here is dated and perishable. A section in `bible/` tries to state what is true about KERI; a file here states what was true of somebody's running infrastructure on an afternoon, with the commands to re-measure it. Read the date before trusting a row.

These are deliberately outside `bible/`, so `build-bible.py` does not fold them into `keri-bible.md` and the review panel does not load them as doctrine.

- [`vlei-discoverability.md`](vlei-discoverability.md) — what each public vLEI data source contains, and the two techniques that bridge the gaps between them.

A companion census of which QVIs publish a `.well-known` surface is deliberately **not** here: it names organisations and their adoption status, which is fair to record and not ours to broadcast. It lives in the private `bakobo/infra` repo at `docs/vlei-qvi-wellknown-census.md`.
